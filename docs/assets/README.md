Open a `.drawio` file in draw.io to move blocks, change labels and reroute
connectors. The README uses the SVG previews.

Both formats are generated by
[render_docs_diagrams.py](../../scripts/render_docs_diagrams.py), using only
Python's standard library. Regenerating overwrites both formats, so keep manual
draw.io edits separately or update the generator before regenerating.

Solid arrows show data transfers or comparison inputs; dashed arrows show
instruction issue. Crossings are not junctions. The core boundary excludes the
behavioral SRAM banks. Performance counters and individual handshake signals
are omitted for clarity.
